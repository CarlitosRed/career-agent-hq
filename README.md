# Career Agent HQ

Private project (not for GitHub public). Improves Carlos's CV and LinkedIn and finds agentic-engineering roles, using the same office model as `advance-po-reader`.

```
career-agent-hq/
  AGENTS.md          Rules for every agent (Codex reads this)
  CLAUDE.md          Pointer to AGENTS.md
  OFFICE-STATE.md    Read first: roster, flow, status
  CONTEXT-RULES.md   How chats stay small
  decisions.md       One to three lines per decision
  evidence/          E-###: every provable claim, with source (the bank)
  cv/  linkedin/     Drafts built only from evidence
  jobs/              Market scans and target roles
  tasks/             Queue and task cards
  audits/ drafts/    Reports and handoffs by chat
  raw/               Carlos's verbatim dumps: current CV, LinkedIn text
  _templates/        Evidence entry, task card
```
