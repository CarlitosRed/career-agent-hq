# Skills lake (private)
One file per company or project in `lake/companies/`. Raw transcripts stay verbatim in `raw/interviews/` (git-ignored, never edited).

Each fact line: `- [level] fact | source: interview <date> or artifact path`
Levels: `verified` (artifact or document checked), `stated` (Carlos said it), `unproven` (memory only, not confirmed).
Also record per company: role and dates, what Carlos did, tools used, results (with numbers only if he gave them), what he did NOT do, limits, what he enjoyed or disliked, people/clients (private), public-safe yes/no.
Interview format: one company per session, 5 to 8 open questions, rounds 2, 3, 4... go deeper as needed (decisions.md).
